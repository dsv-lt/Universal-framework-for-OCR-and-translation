# Grammar & Style Guide for Example Rune Cipher (`_example_demo`)

- **Cipher:** Each rune corresponds deterministically to `a`–`z` (case-insensitive).
- **Intermediate layer:** `postprocess.py` applies ROT13 decoding before translation.
- **Proper nouns:** Preserve `Aethelgard` verbatim without translating.
